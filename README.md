# Tarea-Vlll-lista-completamente-enlasadas

Carlos Daniel Castro Caceres
carnet 9941-24-10004

La tarea consiste en corregir un programa en C++ con errores sobre listas doblemente enlazadas, haciendo que permita insertar, mostrar, buscar, eliminar, contar nodos y liberar memoria; luego crear una segunda versión mejorada usando los punteros head y tail para optimizar la inserción al final y el recorrido hacia atrás, y finalmente comparar ambas versiones explicando las ventajas del uso de tail.
